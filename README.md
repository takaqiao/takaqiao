I'm Taka, a Pathfinder 2e GM who builds Foundry VTT modules and maintains Chinese translations. My work here covers gameplay utilities, localization, and the tooling behind them.

I currently run games on Foundry VTT v14.

## Selected projects

| Project | What it does |
| --- | --- |
| **[Dice So Nice! bridge](https://github.com/takaqiao/pf2e-dsn-persistent-bridge)** | Uses persistent dice thrown on the canvas for PF2e checks, attacks, damage, and rerolls. |
| **[Character audit](https://github.com/takaqiao/pf2e-character-audit)** | Checks PF2e character sheets for prerequisites, build completeness, equipment, and publication sources. |
| **[Encounter XP planner](https://github.com/takaqiao/pf2e-xp-tool)** | Plans encounter budgets with elite/weak previews and options to add or remove creatures. |
| **[Compendium extractor](https://github.com/takaqiao/compendium-extractor)** | Exports Babele translation JSON from Foundry compendium packs while preserving existing translations. |
| **[Translation workflow](https://github.com/takaqiao/fvttAutoTranslateTool)** | A Python workflow for Babele JSON with glossary support, markup checks, and review tools. |

## Localization

Chinese translations for Foundry VTT systems and community content:

- **[PF2e community compendiums](https://github.com/takaqiao/pf2e-compendium-extra-cn)** — third-party modules and compendiums, using Babele.
- **Starfinder 2e** — [system translation](https://github.com/takaqiao/sf2e_cn) and [compendium translation](https://github.com/takaqiao/sf2e_compendium_cn).
- **[Crucible](https://github.com/takaqiao/crucible-cn)** — system translation.
- **[Ember](https://github.com/takaqiao/ember_cn_unofficial)** — unofficial system translation.
- **[Pathbuilder 2e](https://github.com/takaqiao/pathbuilder2eTranslation)** — translation drafts.

## Contributing

Bug reports, compatibility notes, and translation corrections are welcome. Open an issue or a PR in the relevant repository.

For bugs, include your Foundry and system versions and the steps to reproduce. For translation fixes, include the original text and your suggested wording.
